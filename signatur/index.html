In Outlook einfügen

Neues Outlook / Outlook im Browser:

  1. Zahnrad (Einstellungen) → Konten → Signaturen
  2. Neue Signatur, Namen eingeben (z. B. „JDC hell“)
  3. Ins Textfeld klicken und einfügen (Strg+V bzw. ⌘+V), speichern

Klassisches Outlook (Windows):

  1. Datei → Optionen → E-Mail → Signaturen
  2. Neu, Namen eingeben, ins Feld einfügen, OK

Outlook am Mac:

  1. Outlook → Einstellungen → Signaturen → +
  2. Einfügen und speichern
